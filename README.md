# String Matching Algorithms (C++)

C++ implementations of two classic string-search algorithms for finding a pattern in large text.

| Algorithm | Idea | Folder |
|---|---|---|
| **Rabin–Karp** | Rolling hash: compare hash values first, check characters only when hashes match | `Rabin Karp/` |
| **Boyer–Moore** | Scan the pattern right-to-left and skip ahead using the bad-character and good-suffix rules | `Boyre Moore/` |

## Run

Open the `.sln` file of either algorithm in Visual Studio and run, or compile the main `.cpp` file with any C++ compiler.

Algorithms course project – Misr International University (2023).
